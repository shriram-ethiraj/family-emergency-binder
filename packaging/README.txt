Family Emergency Binder Creator
================================

1. Keep this entire folder together. Do not move the HTML file away from assets/.
2. Double-click family-emergency-binder.html.
3. When prompted, choose this package's templates folder.
4. Open or create your encrypted .febvault, then enter its password.

To add a template, copy its JSON file anywhere inside templates/. Close and reopen
the app, then choose the templates folder again. The app reads template files but
does not modify them or send them anywhere.

Chrome, Edge, Firefox, and Safari are supported. Chromium browsers provide direct
in-place vault saving. Firefox and Safari download an updated encrypted vault after
changes; always keep the newest downloaded file.
